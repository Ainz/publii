# Technews adaptations

Adaptations of [Technews](https://marketplace.getpublii.com/themes/technews), a free theme by the Publii team (TidyCustoms) for [Publii](https://getpublii.com).

**The theme itself is not included.** Every adaptation here runs on top of an unmodified Technews installation, through Publii's own Custom CSS and Custom HTML fields ([Tools documentation](https://getpublii.com/docs/tools.html)). Install Technews from the [Publii Marketplace](https://marketplace.getpublii.com/themes/) first.
