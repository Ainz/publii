# Technews adaptations

Adaptations of **Technews** by [TidyCustoms](https://tidycustoms.net) for Publii.

**The theme itself is not included.** Every adaptation here runs on top of an unmodified Technews installation, through Publii's own Custom CSS and Custom HTML fields. You need your own copy of Technews.

| Adaptation | Built on | Used on |
|---|---|---|
| [Typotechtural](Typotechtural) | Technews 3.2.0.0 | [conram.it](https://www.conram.it) |
